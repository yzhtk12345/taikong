Yuzhou Sing-box Extended Manager
================================

一、脚本

文件：yuzhou_singbox_extended.sh
项目：shtorm-7/sing-box-extended（脚本自动查询 GitHub 最新 Linux 发布版）

二、支持范围

- Debian / Ubuntu 及常见 RHEL 系发行版（CentOS、Rocky、AlmaLinux、Fedora 等）
- CPU：x86_64/amd64、aarch64/arm64
- 需要 systemd；用 root 运行

三、开始使用

将脚本上传到 VPS 后执行：

  chmod 700 yuzhou_singbox_extended.sh
  sudo bash yuzhou_singbox_extended.sh install

不带参数运行会显示交互菜单。安装流程先检查系统版本和 CPU 架构，然后安装依赖、可选初始化主机名/管理员账号/SSH、下载扩展版核心、生成独立协议端口与凭据、设置 TLS 证书、写入配置并验证、启动服务及配置 HTTPS 订阅。

系统初始化会更改 SSH 配置。务必保留当前 SSH 会话，并在第二个终端确认新管理员账号和新端口能够登录；只有你确认测试成功后，脚本才会设置 PermitRootLogin no。如果无法确认，则会尝试还原 SSH 配置。

四、协议配置

会创建 9 个独立入站：

1. AnyTLS + TLS
2. AnyTLS + Reality
3. Hysteria2 + TLS
4. Hysteria2 + 域名证书 TLS
5. VLESS + Reality + Vision
6. TUIC v5
7. VLESS + XHTTP + Reality
8. Mieru TCP
9. Mieru UDP

每个入站使用不同的端口和独立凭据。注意：协议规范并不都使用 UUID：AnyTLS 与 Hysteria2 使用密码；Mieru 使用用户名和密码；VLESS 与 TUIC 使用独立 UUID，其中 TUIC 还使用独立密码。

Reality 使用脚本生成的新密钥，而不是照搬示例私钥。TLS 协议共享本项目的证书文件。WARP 可在安装时选择启用，并仅将脚本内列出的 Google/OpenAI 相关域名分流到 WARP。

五、路径

- 扩展版核心：/opt/yuzhou-sbx/sing-box
- 服务端配置：/etc/yuzhou-sbx/config.json
- 私密凭据：/etc/yuzhou-sbx/credentials.env（权限 600）
- 节点详情：/etc/yuzhou-sbx/node-info.txt（权限 600）
- TLS 证书：/etc/yuzhou-sbx/cert.pem
- TLS 私钥：/etc/yuzhou-sbx/private.key
- Caddy 配置：/etc/yuzhou-sbx/Caddyfile
- HTTPS 订阅文件：/var/lib/yuzhou-sbx/subscriptions/
- sing-box systemd 服务：yuzhou-sbx.service
- HTTPS 订阅 systemd 服务：yuzhou-sbx-subscription.service

六、证书和 HTTPS 订阅

先把域名解析到 VPS，再安装。证书流程可复用匹配当前域名且有效的 acme.sh / 旧脚本证书；也可签发 Let's Encrypt 证书，支持 HTTP-01、Cloudflare DNS API、DNSPod DNS API、阿里云 DNS API。DNS API 凭据不会写入本脚本的凭据文件，但 acme.sh 可能会保存它们以供自动续期。

安装完成会输出两类 HTTPS 地址：

- client.json：完整 sing-box-extended 客户端 JSON，包含 Mieru 和 AnyTLS-Reality 配置。
- sub.txt：Base64 编码的兼容分享链接订阅；由于客户端协议格式差异，不包含 Mieru 和 AnyTLS-Reality。要导入全部协议，请使用 client.json。

订阅地址含随机路径令牌；请勿将地址随意公开。订阅端口默认尝试 443；若不可用，可以输入其他端口。若使用非 443 端口，URL 会包含端口号。

七、防火墙

脚本只向 UFW、firewalld 或 iptables 添加必要的 TCP/UDP 允许规则，不会通过清空规则或关闭防火墙来“放行”。云厂商安全组需要登录厂商控制台单独放行。若系统不提供受支持的防火墙管理器，脚本会提示手动处理。

八、常用命令

  sudo bash yuzhou_singbox_extended.sh status
  sudo bash yuzhou_singbox_extended.sh show
  sudo bash yuzhou_singbox_extended.sh restart
  sudo bash yuzhou_singbox_extended.sh logs
  sudo bash yuzhou_singbox_extended.sh firewall
  sudo bash yuzhou_singbox_extended.sh cert
  sudo bash yuzhou_singbox_extended.sh renew
  sudo bash yuzhou_singbox_extended.sh update
  sudo bash yuzhou_singbox_extended.sh prepare
  sudo bash yuzhou_singbox_extended.sh uninstall

九、验证说明

此版本已通过 bash -n 语法检查、服务端/客户端 JSON 生成解析检查、Base64 订阅解码检查，以及 9 个入站端口互不重复的烟雾测试。尚未在真实 VPS 上完成端到端安装；首次安装时脚本会使用下载到目标机的实际扩展版核心分别执行 check，配置未通过检查时不会继续启动服务。
